目的：本应用旨在帮助用户根据指数的历史表现来计算真正能够得到的定投效果。
以往的应用只能面向未来设定确定的收益率，假定资产按照一定收益率持续增长，但现实世界并非如此。
所以，本应用可以告诉我们定投可能需要忍受和承担的真正的风险，可能有多少个不眠的损失之夜。
警示风险只是手段，真正的目的是帮助我们跨过长夜，打好坚实的财务基础，在持久战中胜出。

目的：このアプリは、指数の過去のパフォーマンスに基づいて、積立投資で実際に得られるであろう運用成果を計算することを目的としています。
従来のアプリは将来に向けて一定の利回りを設定し、資産がその利回りで継続的に成長すると仮定するものでしたが、現実はそうではありません。
このアプリは、積立投資において実際に耐えなければならないリスク、そして損失を抱える眠れない夜が何日あるかを教えてくれます。
リスクを警告することは手段に過ぎず、真の目的はその長い夜を乗り越え、しっかりとした財務基盤を築き、長期戦で勝利することです。
